# RuralClass Pedagogical Terminology Glossary

Standardized multi-grade classroom vocabulary across English, Tamil, and Hindi. These terms reflect natural, practical Indian primary school classroom usage rather than overly academic translations.

| English Term | Tamil (தமிழ்) | Hindi (हिन्दी) | Context & Classroom Teacher Usage |
| :--- | :--- | :--- | :--- |
| **Class 3 / 4 / 5** | வகுப்பு 3 / 4 / 5 | कक्षा 3 / 4 / 5 | Primary multi-grade classroom levels in rural schools. Western digits (0-9) used in all languages. |
| **Fraction** | பின்னம் *(Bhinnam)* | भिन्न *(Bhinn)* | Equal portion of a whole unit or whole set. |
| **Decimal** | தசமம் *(Dhasamam)* | दशमलव *(Dashamlav)* | Base-10 fractional representation (e.g. 0.5 = 1/2). |
| **Place Value** | இடமதிப்பு *(Idamathippu)* | स्थानीय मान *(Sthaniya Maan)* | Groupings of units, tens, hundreds using physical bundles. |
| **Word Problem** | சொல் கணக்கு *(Sol Kanakku)* | इबारती सवाल *(Ibaarti Sawaal)* | Everyday village marketplace transaction stories. |
| **Peer Mentor** | தோழர் வழிகாட்டி *(Thozhar Vazhikaatti)* | सहपाठी मार्गदर्शक *(Sahpaathi Maargdarshak)* | Senior or confident student guiding a peer during station practice. |
| **5-Minute Check-in** | 5 நிமிட சரிபார்ப்பு *(5 Nimida Charipaarppu)* | 5-मिनट की त्वरित जांच *(5-Minute ki Twarit Jaanch)* | Short tactile arrival check for students with conceptual gaps. |
| **Concept Bridge** | கருத்துப் பாலம் *(Karuthup Paalam)* | संकल्पना सेतु *(Sankalpana Setu)* | Diagnostic mapping connecting lower-grade causes to higher-grade symptoms. |
| **Shared Lesson** | கூட்டுப் பாடம் *(Kootup Paadam)* | साझा पाठ *(Saajha Paath)* | Single 20-30 min whole-class lesson serving multiple grades at varied depths. |
| **Stations** | கற்றல் மையங்கள் *(Katral Maiyangal)* | कार्य केंद्र *(Kaarya Kendra)* | Differentiated physical activity corners (Teacher, Peer, Independent). |
| **Formative Check** | கற்றல் சரிபார்ப்பு *(Katral Charipaarppu)* | रचनात्मक समीक्षा *(Rachnatmak Sameeksha)* | Low-stress weekly observation check (Friday courtyard exhibition). |
| **Weak Topic** | கூடுதல் கவனம் தேவைப்படும் தலைப்பு | विशेष ध्यान योग्य विषय | The conceptual gap needing intervention (emphasizing topics, never weak students). |
| **Manipulatives** | எளிய கற்றல் பொருட்கள் | सुलभ शिक्षण सामग्री | Zero-cost courtyard materials: pebbles, paper strips, twigs, bottle caps. |
| **Needs Support** | கூடுதல் ஆதரவு தேவை | अतिरिक्त सहयोग की आवश्यकता | Student peer role indicating targeted teacher guidance is priority. |
| **Steady Learner** | சீரான கற்றல் நிலை | नियमित शिक्षार्थी | Student making steady independent progress. |
